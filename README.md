# Ashish's Portfolio

A premium dark-theme developer portfolio for **Ashish Kumar**, built with React, Vite, Framer Motion, and custom CSS.

## Live Portfolio

The site is configured for GitHub Pages deployment through GitHub Actions.

## Features

- Premium dark UI with responsive layouts
- Recruiter-focused hero, about, skills, projects, services, and contact sections
- Real project screenshots for NoteMindAI, Movie Explorer, and Portfolio
- Resume download support
- Social links for GitHub, LinkedIn, and CodeChef
- GitHub Pages deployment workflow

## Tech Stack

- React
- Vite
- CSS
- Framer Motion
- React Icons

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
